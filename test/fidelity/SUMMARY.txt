3-BINARY TRIANGULATION PROPOSAL
================================================================================

To isolate PORT bugs from COMPILER artifacts:

1. emacs-gcc    — stock gcc build (ground truth)
2. emacs-zigcc  — zig cc build of SAME C source (zero ports)
3. zigmacs      — zig cc + Zig ports

Standing invariant: emacs-zigcc ≡ emacs-gcc

If this holds → any zigmacs divergence NOT in emacs-zigcc is a PORT BUG.

See: TRIANGULATION_PROPOSAL.md for merge-ready HARNESS.md §3.1 text.
